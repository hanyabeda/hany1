
# CNN Transfer Learning using VGG16

## Overview
This project demonstrates Transfer Learning and Fine-Tuning using the pre-trained VGG16 model for image classification.

## Model Used
- VGG16 (Pre-trained on ImageNet)
- GlobalAveragePooling2D
- Dense Layer (256 neurons, ReLU)
- Dropout (0.5)
- Softmax Output Layer

## Technologies
- Python
- TensorFlow
- Keras

## Features
- Transfer Learning
- Fine-Tuning
- Image Classification
